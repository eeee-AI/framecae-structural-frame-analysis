# FrameCAE 完整整合版

双击 `启动FrameCAE.cmd` 启动。本目录是唯一的完整工作版本：保留原“曹馨月更新的”版本的六个轻量算例、图像/手动重建和直接强度功能，同时整合了完整项目的节点局部分析、十个归档算例以及历史结果。

## 节点局部分析

完整流程为：导入或建立模型 → `01` 整体空间梁求解 → 恢复切口六分量内力 → `03` 自编曲边 Tet10 局部求解 → 分别查看平衡、网格和截取距离校核。局部模块支持：

- 真实一体节点件与环形对接焊（1–8 根同材料圆管）；
- 自动识别的连续直圆管分段点（不凭空生成球节点或焊缝）；
- 单根圆管理想固支端，以及支座反力与 01 的核对；
- 圣维南圆环剪力传递、有限加载面片、应力通量独立积分、局部网格和截取距离研究；
- 历史 `03` 任务的恢复。旧任务按其保存的几何读取，不会被新版几何静默替换。

`03_Abaqus结果` 中的既有文件是已归档的对照资料；当前网页默认仍使用自编有限元局部流程，Abaqus 验算入口保持禁用状态。

## 完整资料目录

以下目录必须与程序主体一起保存、移动：

```text
FrameCAE/
├─ 02_模型输入/          # 十个归档算例的模型和输入资料
├─ 03_Abaqus结果/        # Abaqus 结果与对照资料
├─ 04_网页计算结果/      # 03 自编局部分析历史任务与网页结果
├─ 六个算例/              # 原更新版的轻量示例
├─ 03参数_可选/           # 原更新版的可选参数文件
├─ verification/          # 原更新版验证记录
├─ framecae/、web/、runtime/、vendor/
└─ 启动FrameCAE.cmd
```

首页“项目算例与保存结果”面板可载入十个归档算例，并恢复它们已保存的 03 作业。新作业会按对应算例写入 `04_网页计算结果`；自定义模型写入 `99_自定义模型`。

## 验证状态说明

资料已随项目迁移，但“有结果文件”“数值求解完成”“网格收敛通过”“截取距离收敛通过”和“独立 Abaqus 一致”仍是不同结论。请在各作业报告中分别查看，勿将历史结果直接泛化到新输入。

运行时请保证整个目录可写，且不要只复制 `web` 或 `framecae` 源码。
