# FrameCAE 六算例完整项目：截面内力＋圣维南版

完整解压后双击 `启动FrameCAE.cmd`。内含Windows64 Python运行环境及依赖，无需另装Python或Abaqus。

当前唯一03流程：网页模型 → 01整体空间梁求解 → 恢复切口六个截面内力 → 圣维南圆环剪力分布和一致加载 → 03自编曲边Tet10。01位移、转角作为整体输出、切口核对和刚体姿态保留，不是局部位移边界。03不改写01，不联合外围梁重新求解。

## 六个算例文件

在 `六个算例` 文件夹中选择一个 `_模型.json`，在网页建模处导入。1是原N5；2—5对应原模型1—4；6是模型3增加均布载荷及自重的副本。网页仍是通用导入，不把这些算例写成建模菜单。

进入01后检查模型并点击“确认并计算”；进入03选择节点、识别并核对几何与网格，然后计算即可。**不要求额外上传03文件**。`03参数_可选` 中的JSON只是恢复本次保存的几何、网格和已有结果的快捷方式。

原N5、模型1、2、3及均布载荷副本随包保留了截面内力＋圣维南的已完成结果。**模型4仅保留整体数字化输入及当前方法的03设置，未附当前方法的03结果**，需自行计算；没有把它的旧结果换标签充当新结果。

本包不含旧的切口位移驱动/平均运动驱动/外围梁实体协调模式、旧模式参数、结果、对照报告或运行脚本。相关B节点求解分支已从交付源码中移除，后端拒绝旧模式请求；Abaqus验算入口禁用，既有Abaqus源文件保留以便同事后续修改。

## 均布载荷

01“图形建模→荷载”或“参数表格”编辑每杆qx/qy/qz，单位N/m，可选全局或局部坐标。旧文件省略坐标系仍按局部解释；整根杆恒定q，可与节点荷载、自重叠加。修改模型或q后旧结果失效，须重新计算01。

算例6：E18全局q=(0,0,-800)N/m；E4局部q=(120,-250,0)N/m，叠加原节点荷载与自重，03分析N7。局部保留段的q按唯一杆轴分区投影为一致体积载荷，保持合力、合矩及12模式梁虚功；区外影响通过01切口内力传递。自重采用01梁线质量ρA·g，不另加实体节点件多出的体积重量。等效线荷载不是实际表面压力。

算例6结果：焊趾3.826928 MPa，肩部4.2262465 MPa，03方程相对残差1.96e-11，守恒和虚功检查通过。云图显示节点平均应力，表格峰值为未平均单侧应力。

## 验证边界

本次功能验证只运行模型3均布载荷副本；包内其他已存结果属于此前完成的当前内力方法结果。单档结果不代表网格/截断距离收敛或独立应力精度通过。模型4当前方法的03求解尚未验证。支座实体、变幅或部分区间q、真实表面压力和焊接热过程不在本轮范围。
